# AI Resume Analyzer

An AI-powered Resume Analyzer built using Flask and Python.

## Features

- Resume Upload
- ATS Score Calculation
- Skill Extraction
- Missing Skills Detection
- Suggested Job Roles
- Recommended Courses
- Beautiful UI

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Bootstrap
- PyPDF2

## How to Run

1. Install the required packages.

pip install -r requirements.txt

2. Run the project.

python app.py

3. Open the browser and visit:

http://127.0.0.1:5000

4. Upload your resume PDF.
